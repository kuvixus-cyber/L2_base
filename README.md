## Запуск тестов

Через Node.js:
```bash
npm test
```

Через встроенный в macOS движок JavaScriptCore (`jsc`):
```bash
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc tests/run-tests.js
```
